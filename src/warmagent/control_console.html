使用顺序

1. 第一次使用：配置与安装 → 补齐缺失配置 → 填写本人账号与渠道。
2. 本地聊天：录入模型密钥 → 选择本地网页或终端。
3. 微信：打开微信登录 → 核验并绑定身份 → 启动微信聊天。
4. QQ：打开NapCat登录，设置机器人账号、本人账号与令牌，再启动微信 + QQ。
5. 看状态：打开运行监视、上下文或生活小本。
