# 2026-10-29 功能说明

本次公开文档同步覆盖近期群聊原文读取、生活小本、空闲主动联系、紧凑记忆索引与记忆评测入口。实现文件和公开基准入口见各节及[架构地图](ARCHITECTURE.md)。

## 群聊近期原文读取

主脑可通过 **read_recent_group_messages** 按消息条数读取本轮投递时冻结的同群原文窗口。每页返回 1—50 条，可用消息 ID 向前分页；当前请求与窗口冻结后到达的消息不会混入结果。数据来自本轮渠道投递，不会搜索全部群聊历史，也不会跨群补足条数。

单页所选消息的正文累计最多返回 10,000 个 UTF-8 字节；单条正文最多提供 500 字符预览，超出时标出正文不完整，并可在原冷归档启用时使用原有单条读取入口核对全文。该工具只读取已有投递材料，不增加 Harness、桌面或电脑控制权限。私聊不挂载这个群聊读取入口。

实现入口：[recent_chat.py](../src/warmagent/recent_chat.py) · [群聊上下文](../src/warmagent/context.py)。

## 生活小本与相关材料

本地监视页和网页聊天入口提供 /personal 页面，以当前会话的本人私聊范围查看随笔、兴趣和已登记文件。随笔按北京时间日期筛选、每页 20 条；兴趣与文件分别展示近期或优先的最多 20 项。查看与下载使用既有会话和 scope，不领取投递、不确认分享、不改动资料，也不唤醒模型。文件按登记 ID 与 scope 读取，并核对登记时的内容 hash；不一致时拒绝下载。

随笔去重保持保守：有来源的记录仅在 scope、种类、来源相同且正文仅有空白格式差异时复用原记录；无来源的主观记录仅在同一北京时间日内去重。新来源或新内容会保留，隔日相同感受也可以单独记录。

聊天按当前话题轻量挑选相关材料，最多附带 2 条随笔、合计 700 个字符，以及 2 张兴趣卡。明确询问近期随笔、兴趣或进展时可展示近期材料；无关内容留空。随笔和兴趣仍是主观记录，不因此变成事实记忆或人格修订。

只有本轮完整引用了选中的未截断随笔原文，才关联对应的笔记版本。整条消息确认送达为 sent 后才记为已分享；部分发送、unknown、改写提及和页面查看都不算分享。旧版本回执不会覆盖新版本状态。

实现入口：[生活小本页面](../src/warmagent/personal_view.py) · [随笔存储](../src/warmagent/personal_space.py) · [相关材料选择](../src/warmagent/personal_relevance.py)。

## 没有目标时也可以主动联系

空闲活动可以在没有当前目标或新成果时，直接向用户发起自然的私聊；也可以选择休息，不虚构任务，不要求写出产物。主动联系继续受现有活动间隔、省费时段和投递 unknown 门控约束，pending 或结果未知的消息不会被当成成功联系而重复发送。用户安排、聊天优先和暂停规则保持原有处理路径。

## 紧凑记忆索引

配置模板在 [bridge.example.toml](../config/bridge.example.toml) 的 [bridge.memory] 提供 compact_index_enabled = true。紧凑读写器可读取旧 JSON 代际，向量与行元数据分开保存：float64 稠密向量写入 .npy 并以只读 mmap 加载，TF-IDF 保留 CSR 稀疏矩阵并写入 .npz。JSON 元数据保存行映射、图与主题、空间签名、水位及 sidecar 文件摘要。

构建仍沿用单调发布流程：完整向量文件先写完，代际元数据随后落盘，最后在原 writer 内比较 archive sequence 并发布 current。读取会核对元数据摘要、sidecar 摘要、身份、水位、shape 与 dtype；失败时保留原 current。后台构建使用现有 worker 和有界 SQLite 内容缓存。mmap 只减少加载时 Python 对象分配，不代表矩阵运算零内存。

核心适配只增加 Application 的可选 index_factory；紧凑格式、索引算法与 worker 连接均位于 WARMAGENT 适配层。回退时须先由紧凑读写器把 current 指向已验证的旧 JSON 代际，再关闭开关并使用旧代码；旧读写器不能加载紧凑代际。

实现入口：[紧凑索引](../src/warmagent/compact_index.py) · [向量格式](../src/warmagent/compact_vectors.py) · [装配入口](../src/myatri/app.py) · [配置模板](../config/bridge.example.toml)。

## 记忆评测

公开仓提供 20 道固定合成问题夹具、检索评测器、只读真实档案采样导出脚本，以及紧凑索引合成性能脚本。真实档案抽样和逐题报告由部署者在本机生成，保存在忽略的 reports 目录；公开仓只发布固定合成问题与合成基准，不发布真实记忆样本或逐题结果。

评测器测召回、排序和证据呈现，不生成聊天回答，也不额外调用回答或裁判模型。因此，检索命中不等于回答已经正确使用证据；回答质量仍须另行核对。定义、命令和口径见[记忆评测说明](MEMORY_EVALUATION.md)。
