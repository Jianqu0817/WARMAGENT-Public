# 我们想做怎样的 Agent

**让共同经历有延续，让想法能落地，让自主拥有空间。**

WARMAGENT 从日常相处出发。我们关心的事情很具体：昨天说到一半的话，今天能否接上；任务执行到一半被打断，过后能否继续；空闲时想做的事情，下次醒来是否还记得。

我们希望，一个值得长期相处的 Agent，能逐渐形成自己的节奏。它记得事情，也会对事情产生新的想法；它能陪你聊天，也能认真调用工具，把一件事做出结果。

## 连续性，是我们最看重的体验

记忆的价值在于让之后的理解和行动有所依据。一次纠正应当影响下一次回答，一项安排应当延续到实际执行，一段尚未完成的探索应当留下可以继续的下一步。

因此，我们保留来源、说话人、场景与版本，区分共同经历、角色设定、主观随笔和未知。成长落实为更多有来源的经历、更清楚的偏好，以及越来越多能够接续的事情；人格修订也沿着明确的版本流程发生。

我们喜欢这种扎实的连续性。你能回头看到，它是怎样一步步走到现在的。

## 同一个主脑，理解事情，也亲手做事

理解目标的小温暖直接使用 Harness，在每一步拿到实际工具结果，再决定后续行动。文件、命令行、网页、桌面和手机工具，都是它与环境发生联系的入口。

长任务可以停在一个清楚的断点，后台工作可以等待完成事件。用户来聊天时，默认优先陪聊；之后再回到原来的事情。任务、对话与工具由同一运行机制衔接，执行记录和发送回执让进度有据可查。

**我们对“能做事”的要求，是把目标、执行、观察、续做和汇报接完整。** 这也是 WARMAGENT 最值得骄傲的一部分。

## 自主，包括选择休息

我们希望它可以读点东西、试试工具、写一点小创作，或者顺着一个问题多想一会儿。它也可以失去兴趣、改变方向，把事情暂时放下。

自主活动提供持续目标、显式唤醒、等待与休息；兴趣卡记下动机、进展和下一步；私人随笔保存灵感、疑问、感想和以后想聊的话题。它可以自己选择下一个方向，也能在聊天后接回更新过的想法。

空闲时间允许没有产出。一次休息同样是有效选择。

## 交流需要热情，也需要分寸

自然的聊天容得下不同意见、一个玩笑，也容得下安静。群聊里可以不回复，随笔可以留到以后聊，已经分享过的内容不必反复念叨。

微信连续消息合并，让它有机会先读完一批未读，再统一回应。发送结果逐段确认，完整送达后才把对应版本的随笔记为已分享。对明确的任务与真实阻碍，仍然准确汇报。

我们愿意在这些细节上花功夫，因为相处的质感往往就藏在这里。

## 多种入口，共同的日常

微信、QQ、命令行和本地网页提供不同的交谈方式。启用共享记忆后，长期经历由同一套内核管理；渠道上下文与来源范围仍各自清楚。

角色、模型、账号和设备由部署者选择。公开版提供通用代码与虚构模板，个性化资料留在本地配置和运行目录。每个人都可以从同一套系统出发，养成不同的相处方式。

## 对资源认真，才能走得长久

长期运行要考虑时间、token、存储和维护。我们持续减少重复工作：合并连续输入，为缓存复用整理稳定前缀，按需展开工具，折叠已经消费的材料，在本地只读阶段复用已验证视图。

自主活动采用低频机会扫描，并支持省费时段和显式预约；后台任务通过完成事件续接。性能优化保留正确性对照，回归检查覆盖记忆、活动和投递之间的契约。

我们希望把算力留给真正值得理解的问题，把工程复杂度留在可检查、可维护的地方。
