# 可视化操作台与入口地图

统一入口：双击根目录 **Start.cmd**。浏览器打开 `http://127.0.0.1:8770`，不需要先启动聊天。旧CMD全部保留，操作台直接复用原启动器、配置、共享记忆和服务互斥锁。

## 日常操作

1. **总览与启动**：选择微信、微信＋QQ、本地网页或终端，分别保留正式/离线模式。已有聊天运行时先点击“正常停止聊天”，等管理端口和旧任务退出再切换。
2. **渠道与工具**：打开微信/NapCat登录、启动或停止Reader、打开专用浏览器；登录在原客户端完成。
3. **配置与安装**：填写本人稳定账号、渠道白名单、模型、预算、心跳、省费时段、消息合并、索引、ADB路径/serial。高级选项用本机编辑器打开固定配置文件；模型密钥在独立窗口隐藏输入。
4. **任务与输出**：查看本次操作台启动的进程、退出码、末尾输出，也可读取原聊天、Reader和观察页日志。交互任务请查看独立窗口。
5. **文档与旧入口**：搜索README/docs文档和CMD文件名，查看原文及按钮对照。展示使用纯文本，不执行文档中的指令。

“运行监视”继续提供今日Token、PAD、记忆、活动/唤醒、后台任务及运行时回复概率设置；“上下文”与“生活小本”沿用原页面。端口亮灯只说明正在监听，不冒称已经登录或模型可用。

首次没有Python环境时，Start.cmd先运行原Setup.cmd（需预先安装Python3.12与uv），成功后打开操作台。已有环境时不自动更新依赖、登录、发消息或启动模型。

## 启动与配置

```powershell
.\Start.cmd
# 等价入口
.venv\Scripts\python.exe -m warmagent console
# 另一个项目占用默认控制台端口时
.\Start.cmd --port 8771
```

控制台默认8770，聊天网页8769，监视8767，上下文8768；管理端读取主配置端口，默认8766。重复打开同一项目会复用控制台；另一个项目占用该端口时明确报错，不展示它的配置。控制台使用独立`var/control-console.lock`，不领取聊天的`service.lock`。

关闭浏览器不关闭控制台服务；在控制台窗口按Ctrl+C只退出控制台，不停止已启动的聊天、Reader、微信或设备。聊天退出继续走原Stop-Chat的身份/进程核验与Ctrl+C，不强制杀进程。

配置保存只写实际修改字段，保留其他字段与注释；保存前比较原文件摘要，过期页面不能覆盖其他修改。备份在`var/backups/control-config/`。多行复杂TOML不能确定替换时保留原文件，转本机编辑器修改。保存不热重启，下一次正常启动加载。紧凑索引不能由表单直接关闭，须先依原文档回退旧JSON代际再降级。

安装与维护同类操作串行；聊天运行时不启动安装/维护或第二套聊天。角色卡、库路径/范围和账号绑定仍按原机制生效，不因编辑表单迁移或重置记忆。新增私人卡首次从当前卡复制到忽略的`config/persona/persona.local.md`，随后需在主配置指定路径；不会直接改已有库的人格。

## 工程入口与契约

| 文件 | 职责 |
| --- | --- |
| `Start.cmd` / `__main__.py console` | 安装缺失环境后启动独立控制台 |
| `console_catalog.py` | 固定操作目录、旧CMD对应、交互窗口与任务互斥分组 |
| `control_console.py` | loopback HTTP、会话/CSRF、固定参数派发、进程状态、日志与文档读取 |
| `console_settings.py` | 白名单表单、TOML结构核对、摘要冲突与原子保存/备份 |
| `control_console.html/css/js` | 五页界面、按需配置加载、5秒轻量状态刷新、纯文本输出 |
| `tests/test_control_console.py` | 临时配置、假进程、HTTP会话、来源限制、CMD目录覆盖 |

请求只接受固定操作ID，不接受网页提供的命令、参数或任意文件路径；Windows任务各用独立控制台，普通任务隐藏窗口并写本地输出，交互任务保留可见窗口。关闭控制台不会向子进程发送取消。子进程启动/退出记录不等于登录成功或业务完成。

监听仅127.0.0.1；API需要同源会话，写操作还需Origin和CSRF。页面不显示模型Key或QQ令牌，凭据录入不经过HTTP。操作日志可能含本机账号与路径，只保存在ignored的var，勿上传。

## 已验证与未验证

开发目录6项最小离线测试及Ruff/JS语法检查通过；在临时演示目录实际浏览首页、配置、文档及CMD对照，保存反馈正常。真实Windows子进程派发另用无副作用的帮助命令/合成CMD核对。未启动正式聊天、停止现有服务、登录渠道、运行安装器、控制设备或调用模型。Public移植仅做静态差异、链接及隐私/历史检查，按用户要求不运行移植测试。

最小复验：`.venv\Scripts\python.exe -X utf8 -m pytest tests/test_control_console.py -q`。控制台支持运行旧验收/基准按钮，但它们只在用户点击后执行。
