# 为什么选择 WARMAGENT

**WARMAGENT 的竞争力，是围绕一个长期相处的 Agent，把记忆、聊天、自主活动和实际行动接得完整。**

当你关心的是“它能不能认真接话、记得来龙去脉、做自己的事情、被打断后继续”，这套设计就很有针对性。我们把这些体验放进了收件箱、活动状态、记忆版本与投递回执，形成可以检查和继续打磨的工程实现。

## 我们真正打磨了哪些细节

### 1. 先读完一批未读，再认真回答

微信私聊中的连续输入进入持久未读窗口。生成期间的新补充可以触发重整，尚未发送的草稿也可以继续吸收消息；已经执行的工具结果仍保留。

对经常连发几句话的人，这直接对应一种更舒服的交谈节奏。它也减少为过时输入继续排队回答的浪费。

实现与夹具：[runtime_inbox.py](../src/warmagent/runtime_inbox.py)、[reading_conversation.py](../src/warmagent/reading_conversation.py)、[未读合并测试](../tests/test_wechat_unread_batch.py)。

### 2. 能陪你，也有自己的下一步

默认 chat_first：用户来聊天时优先交流，安静一段时间后接回活动。目标、进展、下一步、显式唤醒和后台等待都能保留；用户也可以插入安排或调整方向。

自主活动允许探索、娱乐、创作和休息，兴趣有进展，随笔能留待下次聊。这组机制服务于连续的个人日常。

实现与夹具：[activities.py](../src/warmagent/activities.py)、[activity_runner.py](../src/warmagent/activity_runner.py)、[兴趣与自主选择测试](../tests/test_autonomy_choices.py)。

### 3. 理解任务的主脑，亲自读完工具结果

聊天与自主活动复用同一逻辑主脑，直接进行原生工具调用。工具结果回到相应的对话协议；后台工作完成后再沿事件和报告流程续接。

我们把“为什么做、实际做了什么、下一步怎么走”留在可接续的执行链里。长期任务与日常插话可以在同一运行体系里协调。

实现与夹具：[direct_harness.py](../src/warmagent/direct_harness.py)、[background_jobs.py](../src/warmagent/background_jobs.py)、[活动执行测试](../tests/test_activity_runner.py)。

### 4. 记忆有来处，误会有机会澄清

档案保留来源与版本；群聊原话、私聊、转述、角色设定和主观随笔各有自己的位置。修正可以留下版本线索，读取也遵循范围与截止点。

这让我们能具体检查：它记住的内容是谁说的、何时发生的、有没有被修正。对于长期相处，这份可追溯性很重要。

实现与夹具：[archive.py](../src/myatri/storage/archive.py)、[context_read_view.py](../src/warmagent/context_read_view.py)、[记忆证据测试](../tests/test_memory_evidence.py)。

### 5. 发出去的话，才算真正告诉你

自主分享经过持久 outbox，分段发送逐段确认。与随笔关联时，整条消息确认送达才标记对应版本已经分享；准备后修改的笔记不会被旧消息误标。unknown 保留为待核对状态。

这份细致，是我们很看重的可靠性：让 Agent 对“已经告诉你”有准确的依据，也给延迟、失败和恢复留下清楚的处理路径。

实现与夹具：[bridge.py](../src/warmagent/bridge.py)、[personal_space.py](../src/warmagent/personal_space.py)、[分享与投递垂直切片](../tests/test_personal_autonomy.py)。

### 6. 从入口到存储，都认真对待开销

输入合并、稳定前缀、按需工具目录、低频机会扫描、省费时段和后台完成事件，分别处理重复生成、上下文负担与空转。档案、索引和投递查询继续减少重复读写与计算。

我们把成本放在日常运行机制里考虑。你可以查看预算、运行状态与执行记录，再决定怎样分配资源。

实现与夹具：[request_context.py](../src/warmagent/request_context.py)、[tool_catalog.py](../src/warmagent/tool_catalog.py)、[性能契约测试](../tests/test_perf_archive.py)。

## 我们的底气

**记忆有来源，行动有回执，自主有断点，交流有分寸。** 我们把这几件事放在同一条生活主线上，做出了一个有鲜明取舍、能够继续打磨的个人 Agent。

公开发布前的248项离线回归与2项发布检查测试，为当前实现提供契约证据；范围见[版本状态](STATUS.md)。第三方来源与借鉴保留在源码注释及许可证中。
