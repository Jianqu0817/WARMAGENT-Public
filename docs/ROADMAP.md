# 路线图

路线按公开代码入口、尚未完成的评估和明确暂缓的工程分开列出。性能指标只描述对应的合成局部路径，不推算整轮聊天速度。

## 已进入公开代码

- 同群近期原文窗口按消息条数分页读取，并固定在本轮投递快照内。
- 本地生活小本只读页面、保守去重、话题相关材料选择和精确版本分享回执。
- 无目标或无新成果时仍可主动私聊用户或选择休息，沿用原间隔、省费和 unknown 门控。
- 可选紧凑索引：只读 mmap 的 float64 .npy 稠密向量、CSR TF-IDF .npz、sidecar 完整性校验、后台构建、旧格式读取与双向回退。
- 固定合成记忆题集、真实档案只读采样入口和紧凑索引合成基准。

这些条目说明源码与工具入口已进入公开树。本次文档同步没有运行移植后的功能或性能测试，也没有启动服务或浏览器。

## 下一步评估

- 扩充固定合成题集之外的本地问题标注，重点检查目标已召回但没有排在首位的改写问题；先增加独立问题与证据标签，再决定是否调整排序。
- 在部署者自选的真实档案快照上记录事件召回、原文证据、排名、预算裁剪和延迟分位数。抽样结果仅用于该部署者的本地评估，不作为公开真实记忆样本。
- 完整回答质量需要另行准备答案及引用核对；检索评测器不生成答案，也不代替人工确认回答是否准确使用证据。

## 明确暂缓

- **自动空间治理仍待实施。** 当前设计草案为达到 20 GiB 时触发回收、尽量降至 18 GiB、应用受管写入上限 50 GiB。共享容量账本、写入预留、恢复点轮换和自动回收尚未接入，公开文档不将这些门槛写成已生效保护。
- **完整规模与硬件验证暂缓。** 240 条记录的合成短测不能代表部署者的全量记忆库。尚未据此宣称生产规模、GPU 加速或跨设备吞吐收益。
- **ANN 近似索引暂缓。** 当前精确搜索仍是基线；在真实规模下评估召回损失、构建成本和查询 P95 前，不引入 Faiss、HNSW 等近似检索替换。

## 音乐互动场景（规划）

音乐互动仍是规划，不代表已安装、登录或控制播放器。首版目标是按用户请求共同选曲，读取曲目与播放状态，发起播放或暂停后再读取状态确认；没有可用客户端时提供可核对的链接，不声称已经播放。设备控制沿用现有稳定用户授权、动作锁和 unknown 核对流程，不增加执行 Agent 或定时模型轮询。

后续可评估本地客户端提供的状态读取、少量候选检索和播放控制接口。真正的跨设备同步听歌另行依赖平台原生能力和双方连接；单台本地播放器处于播放状态，不代表其他设备正在同步。

详细接口和首版操作流程见[音乐互动场景计划](音乐互动场景计划.md)。
